# Generative AI Research
This repository was created for the REIT6811 Applied Class 6 activity.
## Purpose
This repository is used to organise research data and project files and to practice GitHub and version control.
## Project Structure
- Literature_Review: Journal articles, conference papers, books, and other literature.
- Quantitative_Analysis: Survey data, survey questions, Python scripts, CSV files, Excel files, and analysis reports.
- Qualitative_Analysis: Interview transcripts, interview protocols, consent forms, analysis reports, and data visualisations.
- Drafts_and_Reports: Draft research proposals, conference papers, and final reports.
- Additional_Materials: Information sheets, photos, and other media files.
## Navigation
Open the relevant folder according to the type of research material you want to view or edit.
## Contribution Guidelines
Future collaborators should place files in the appropriate folder and use clear and consistent file names. Changes should be committed with meaningful commit messages and pushed to the repository.
